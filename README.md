# MATLAB-Simulink-Projects
A collection of electrical engineering projects developed using MATLAB and Simulink. This repository contains simulation models, MATLAB scripts, and simulation results used to analyze electrical systems and engineering concepts.

## 📌 Repository Contents

- MATLAB Scripts (".m") — Calculations, numerical methods, data processing, and result analysis.
- Simulink Models (".slx") — Block-diagram models of electrical systems and dynamic processes.
- Simulation Results — Plots, waveforms, and other outputs generated during simulations.

## 🛠️ Tools & Technologies

- MATLAB
- Simulink
- Control System Toolbox (when required)
- Simscape Electrical (when required)

## 🚀 How to Run

1. Clone or download this repository.
2. Open MATLAB and set the project folder as the current working directory.
3. Open the desired ".slx" file in Simulink.
4. Run the associated MATLAB script, if required, to initialize parameters.
5. Run the simulation and inspect the outputs using Scope blocks or MATLAB plots.

Note: Some projects may require additional MATLAB toolboxes. Check each project's README for its specific requirements.

## 📊 Simulation Results

Simulation results are included where applicable to demonstrate system behavior and support the analysis. Results may include time-domain responses, electrical waveforms, and comparisons between calculated and simulated values.

## 🎯 Objectives

- Apply electrical engineering theory to practical simulation models.
- Develop MATLAB programming and Simulink modeling skills.
- Analyze system behavior under different operating conditions.
